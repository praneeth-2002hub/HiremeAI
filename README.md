# Hiremeai 🚀

An AI-powered resume chatbot that allows recruiters to interact with my professional profile through a conversational interface.

## Features
- AI-powered conversational interface
- Resume-based question answering
- React frontend with an outer-space theme
- FastAPI backend
- Groq LLM integration
- Animated typing indicator

## Tech Stack
- **Frontend:** React, Vite, CSS
- **Backend:** Python, FastAPI
- **LLM:** Groq API
- **Other:** REST API, Git, GitHub

## Project Structure
- `backend/` – FastAPI application and AI integration
- `frontend/` – React user interface

## Run Locally

### Backend
Activate your Python virtual environment, install dependencies, configure your Groq API key, and run the FastAPI server.

### Frontend
Install dependencies using `npm install` and start the development server using `npm run dev`.
